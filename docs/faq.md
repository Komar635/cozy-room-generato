# FAQ

## Сколько фотографий нужно для сканирования?

Минимум 10. Для более стабильного результата лучше загрузить 20-30 фотографий с разных ракурсов.

## Какие форматы изображений поддерживаются?

JPEG, JPG, PNG и WebP. Максимальный размер одного файла — 10 MB.

## Можно ли запустить сканирование без Python-сервисов?

Нет. Next.js API вызывает photogrammetry service через `PHOTOGRAMMETRY_SERVICE_URL`. Без сервиса маршрут сканирования вернет ошибку интеграции.

## Используются ли реальные внешние сервисы в тестах?

Нет. Интеграционные тесты задачи 19 фиксируют контракты полного цикла без реальных Supabase, Gemini, photogrammetry и modification сервисов.

## Почему нет Playwright E2E тестов?

Playwright не установлен в проекте, а текущая задача запрещает запуск dev-сервера. Вместо браузерного runtime добавлен browserless E2E contract harness, который фиксирует сценарии, API маршруты и UI-сигналы без запуска браузера.

## Удаляется ли оригинальная модель при модификации?

Нет. Контракт модификации всегда отправляет `preserve_original: true`, а новая модель сохраняет ссылку на исходную через `parent_model_id`.

## Где смотреть прогресс обработки?

На странице проекта в блоке `Сканирование и прогресс`. API-статус доступен через `GET /api/projects/[id]/scan/status` и `GET /api/projects/[id]/modify/status`.

## Как получить PDF со спецификацией материалов?

Откройте блок материалов после завершенной модификации и используйте экспорт через печать браузера.

## Что означает статус `ready`?

Проект готов к просмотру: сканирование завершено, и приложение ожидает доступную запись модели в `models_3d`.

## Что делать, если модель не отображается?

Проверьте, что у записи модели есть корректный `url`, сервисы завершили обработку без ошибок, а браузер может получить ассет по ссылке.
